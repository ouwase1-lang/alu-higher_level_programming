# python-almost_a_circle

A small package of shapes, covering inheritance, validation, `*args` and
`**kwargs`, JSON serialization and unit testing.

- `models/base.py`: `Base`, which manages ids, JSON and files
- `models/rectangle.py`: `Rectangle`
- `models/square.py`: `Square`
- `tests/`: unit tests

Run the tests from this directory:

    python3 -m unittest discover tests
