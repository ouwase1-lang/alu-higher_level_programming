# python-network_1

Python scripts that send HTTP requests with `urllib` and `requests`.

- `0-hbtn_status.py`: fetches the intranet status page with `urllib`
- `1-hbtn_header.py`: displays the `X-Request-Id` header with `urllib`
- `2-post_email.py`: posts an email with `urllib`
- `3-error_code.py`: displays the body or the HTTP error code with `urllib`
- `4-hbtn_status.py`: fetches the intranet status page with `requests`
- `5-hbtn_header.py`: displays the `X-Request-Id` header with `requests`
- `6-post_email.py`: posts an email with `requests`
- `7-error_code.py`: displays the body or the HTTP error code with `requests`
- `8-json_api.py`: searches for a user and reads the JSON response
- `10-my_github.py`: displays your GitHub id using Basic Authentication
