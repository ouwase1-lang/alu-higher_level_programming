The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class from the module:

    >>> MyList = __import__('1-my_list').MyList

Check that the module, the class and the method are documented:

    >>> len(__import__('1-my_list').__doc__) > 1
    True
    >>> len(MyList.__doc__) > 1
    True
    >>> len(MyList.print_sorted.__doc__) > 1
    True

Check that ``MyList`` inherits from ``list``:

    >>> issubclass(MyList, list)
    True
    >>> isinstance(MyList(), list)
    True

Sort an unsorted list, and check the original is not modified:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

An empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

A list with a single element:

    >>> my_list = MyList([7])
    >>> my_list.print_sorted()
    [7]

A list that is already sorted:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

A list in reverse order:

    >>> my_list = MyList([3, 2, 1])
    >>> my_list.print_sorted()
    [1, 2, 3]
    >>> print(my_list)
    [3, 2, 1]

Negative numbers:

    >>> my_list = MyList([-1, -5, 3, 0, -2])
    >>> my_list.print_sorted()
    [-5, -2, -1, 0, 3]

Duplicated numbers:

    >>> my_list = MyList([2, 1, 2, 1, 3, 3])
    >>> my_list.print_sorted()
    [1, 1, 2, 2, 3, 3]

The list can still be changed after sorting:

    >>> my_list = MyList([3, 1, 2])
    >>> my_list.print_sorted()
    [1, 2, 3]
    >>> my_list.append(0)
    >>> my_list.print_sorted()
    [0, 1, 2, 3]
    >>> print(my_list)
    [3, 1, 2, 0]
